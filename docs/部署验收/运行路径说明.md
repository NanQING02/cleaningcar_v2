# 运行路径说明

项目运行时会读写以下路径。

## 配置文件

- 默认主配置：`configs/config.json`
- 备用配置：`configs/config_绕行.json`

## 模型路径

- 检测模型：`models/detection/best.rknn`
- 车牌检测：`models/plate/plate_detect.rknn`
- 车牌识别：`models/plate/plate_rec_color.rknn`

## 检测后处理切换

由配置项控制：

- `video.fp_output_mode=6`
  - 默认模式
  - 9 输出模型也只用 `box + class`
- `video.fp_output_mode=9`
  - 使用 `box + class + score`

## 主程序输出目录

### 事件输出

由 `event_output_dir` 控制，例如：

- `events/config`
- `events/config_绕行`

目录内通常包含：

- 事件 JSON（仅 `logic.enable_event_disk=true` 时保存）
- `event_log.csv`（开启事件日志路径时）
- 上传队列数据库

### 截图输出

由 `event_capture_dir` 控制，例如：

- `/data/ftp/event_captures/config`
- `/data/ftp/event_captures/config_绕行`

事件图片会按日期和小时继续分目录：

- `/data/ftp/event_captures/config/YYYYMMDD/HH/`
- `/data/ftp/event_captures/config_绕行/YYYYMMDD/HH/`

说明：

- 当前默认 `system.api.capture_mode=path`，平台收到 `captureImage` 后按路径取图。
- 如果改为 `base64`，平台收到图片数据；本地图片仍会生成，但不再是平台取图必需条件。

### 启动截图

由 `system.startup_capture_dir` 控制，默认：

- `captures/startup`

说明：

- 这是自动启动截图目录
- 当主流程首次真正产出结果后，会自动保存启动截图到这里

### 手动截图

由 `system.manual_capture_dir` 控制，默认：

- `captures/manual`

### 调试帧

由 `video.debug_frame_path` 控制。

默认按 `system.device_id` 自动隔离，例如：

- `/dev/shm/cleaningcar_runtime/RK3588-DEV/debug.jpg`
- `/dev/shm/cleaningcar_runtime/RK3588-DEV-绕行/debug.jpg`

说明：

- 当配置为空或仍使用旧默认值 `/dev/shm/cleaningcar_debug.jpg` 时，会自动切到各自命名空间
- 如果显式填写了自定义调试图路径，则保留用户路径

### 单车视频

由 `logic.per_id_video_dir` 控制，默认：

- `video_result/per_id`

说明：

- 配置为空或只填空白时，等价于默认本地目录
- 如果配置路径不可写，运行时会自动回退到 `video_result/per_id`

### 运行产物清理

当前运行产物清理开关默认禁用，不会主动删除事件图片、事件 JSON、单车视频或日志。

## 运行控制文件

### 心跳文件

由 `system.heartbeat_path` 控制。

默认按 `system.device_id` 自动隔离：

- `/dev/shm/cleaningcar_runtime/<device_id>/heartbeat.json`

### 启动标志

由 `system.startup_flag_path` 控制。

默认按 `system.device_id` 自动隔离：

- `/dev/shm/cleaningcar_runtime/<device_id>/started.flag`

### 命令目录

由 `system.command_dir` 控制。

默认按 `system.device_id` 自动隔离：

- `/dev/shm/cleaningcar_runtime/<device_id>/cmd/`

支持放入：

- `*.cmd.json`
  - 例如 `keep_snapshot` 命令

补充说明：

- 上述 3 项在配置为空、空白、或仍保持旧默认值时，运行时都会自动切到对应 `device_id` 的命名空间
- 如果你显式填写了自定义路径，则运行时保留该自定义路径
- 多路部署时，`system.device_id` 必须唯一，否则仍可能发生运行时文件冲突

## Web 相关

手工模式会产生：

- Web 日志：`web_server_8000.log`
- Web pid 文件：`web_server_8000.pid`

共用访问入口：

- Web 入口：`http://<设备IP>:8000/`
- 推理日志目录：`logs/inference/`
