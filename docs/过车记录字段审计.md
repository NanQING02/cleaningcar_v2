# 过车记录 type1～type6 字段审计

本文定义本地事件 JSON、工作台展示和大模型输入的边界。甲方上报协议仍以 `docs/甲方平台适配说明.md` 为准。

## 阶段语义与展示

| 类型 | 业务语义 | 本地必须保存 | 工作台直接展示 | 大模型输入 |
| --- | --- | --- | --- | --- |
| type1 | 车辆进入检测区 A，本次生命周期开始 | `id`、`type`、`captureTime`、车道、车辆/车牌快照、异常状态、截图 | “进入检测区 A”、时间、截图、异常 | 是 |
| type2 | 车辆进入冲洗区 B，冲洗过程窗口开始 | type1 公共字段；进入 B 的时间、截图 | “进入冲洗区 B”、时间、截图、异常 | 是 |
| type3 | B 区内首次检测到水流；没有检出水时不产生 | 公共字段、`washStartTime`、截图 | “检测到水流”、时间、截图 | 是；作为冲水直接证据，但不是必有阶段 |
| type4 | 车辆退出冲洗区 B，冲洗过程窗口结束 | 公共字段、有效检水 `washDuration`、截图 | “退出冲洗区 B”、时间、有效检水时长、截图 | 是 |
| type5 | 车辆退出检测区 A，形成最终业务记录 | 公共字段、`washEndTime`、`totalWashDuration`、方向、车轮结果、录像时长、最终截图、异常状态 | 最终时间、有效检水时长、方向、左右轮、异常、截图 | 是；最终结果以 type5 为准 |
| type6 | 单车录像生命周期结束通知，不属于冲洗过程 | `id`、`type`、`captureTime`、`lane`、`perIdVideoEnabled`；本地可保留末帧和车辆快照用于排障 | “单车录像结束”、时间、是否启用录像、可播放录像 | 否 |

## 公共字段分层

工作台摘要直接显示：

- 业务 ID、配置/设备、车道、车牌、车牌颜色、车型。
- type1～type6 阶段名称、时间、阶段异常和阶段截图。
- type2～type4 冲洗窗口；type3 是否出现；type4/type5 的有效检水时长。
- type5 的 `directionLabel`、最终异常、左右轮结果。
- type6 的 `perIdVideoEnabled` 和实际可播放的单车录像。

仅在“原始事件”排障区保留，不占用主摘要：

- `trackId`、识别置信度、颜色来源、方向来源、锚点停留帧等算法诊断字段。
- `sourceFile`、截图绝对路径、录像绝对路径等服务器路径。

禁止送给大模型：

- 截图、录像、图片 Base64、文件路径、RTSP 地址及密码、API Token。
- type6 录像结束事件和纯调试字段。

## 聚合规则

- 是否为完整记录以 type5 是否存在为准；type6 不能把进行中的业务记录误判为已结束。
- 车牌、车型、冲洗时长、方向、车轮和最终异常以 type5 为最终快照。
- type6 只能补充录像结束时间和录像状态，不能覆盖 type5 业务字段。
- type3 是条件事件，不纳入“必需阶段缺失”判断；没有 type3 表示算法没有记录到水流，应进入报告待复核项。

## 大模型报告缓存

- 模型完整返回后，报告自动保存到对应 `event_output_dir/agent_reports/`。
- 再次打开同一配置、同一业务 ID 时直接读取本地报告，不调用模型。
- 手动点击“重新分析并更新”才再次调用模型；成功后原子覆盖旧缓存。
- 中止或生成失败不会覆盖旧缓存。
