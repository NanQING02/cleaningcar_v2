# docs 文档索引

`docs/` 里的文档分成两类：

- 当前仍有效的运行 / 部署 / 对接 / 验收文档
  - 这些文档默认面向"现在这份仓库"
  - 适合第一次接手项目或给其他 agent 建立上下文
- 条件性 / 专项 / 带时间基准的文档
  - 这些文档通常绑定某次甲方环境、某轮性能评估或某个专项问题
  - 不能直接当成当前代码和默认配置的唯一事实来源

建立上下文时，建议先看仓库根 `README.md`，再回到本目录。

## 建议阅读顺序

1. `../README.md`
2. `../cleaningcar/README.md`
3. `../configs/README.md`
4. `部署验收/运行路径说明.md`
5. `部署验收/心跳与截图对接说明.md`
6. `部署验收/板端验收清单.md`

如果现场涉及甲方板端硬解链路缺失或双路性能压测，再看：

- `部署验收/甲方MPP环境与补齐要求.md`
- `部署验收/部署前性能评估与低风险优化建议.md`

  - 当前仍有效：环境目录说明、运行路径说明、心跳与截图对接说明、板端验收清单
  - 条件性：`甲方MPP环境与补齐要求.md`（绑定特定甲方板端环境，合并自原"甲方设备MPP环境说明"等三份文档）、`部署前性能评估与低风险优化建议.md`（带时间基准）
- `RGA运行默认策略.md`

## 阅读提醒

- 当前代码、默认配置和主链路说明，以根目录 `README.md`、`configs/README.md`、`cleaningcar/README.md` 以及实际代码为准
- 当前视频链路口径是：`FFmpeg 硬解/硬编优先 -> GStreamer+mpp / GStreamer 硬件链路次选 -> 软件链路兜底`
- 当前已删除全局视频保存功能，仅保留 `logic.enable_per_id_video`
- 当前 Web 不再浏览单车录像，实时调试画面改为点击获取
- 看到"甲方""某轮评估""专项口径"这类表述时，要先确认该文档是不是你当前场景
